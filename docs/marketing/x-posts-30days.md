### Day 17 (Wed) — Technical Deep Dive
> How SHOGUN's memory works:
>
> 1. Desktop captures screen text (Tesseract OCR)
> 2. Text chunked + embedded (text-embedding-3-small)
> 3. Stored in pgvector (1536 dims)
> 4. Semantic search at chat time
>
> Your work history, always accessible to AI.
